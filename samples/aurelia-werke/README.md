# Aurelia Werke GmbH: sample data

Aurelia Werke GmbH is a fictional automotive components manufacturer in Bavaria, reporting in EUR.
Every figure, name and lender relationship here is invented for testing and demonstrations.

| File | Contents |
|---|---|
| `aurelia-werke.xlsx` | The full data set: exposures, hedges, policy, financials, bank accounts, cash flows, facilities, covenants, deposits and repayments |
| `05-company-financials.csv` | Headline financials |
| `08-debt-facilities.csv` | Three debt facilities |
| `09-covenants.csv` | Covenants on those facilities |
| `12-facility-schedule.csv` | Repayment schedule |

Used by `/cfo-toolkit:check-setup` and the toolkit's own tests.
